Where the three agents agreed

Strong consensus

  • 6 missing components in the inventory (Sally). Presence Avatar Stack (overlapping dots on Set row showing who's editing, FR-1 + FR-25). Conflict Toast (non-modal last-write-wins notification). Risk Banner (ACWR alert with primary action, FR-37). Ghost Set Row (AI-suggested set with accept/dismiss gesture, FR-12 + FR-14 — distinct from standard Set row, different interaction model). Session Recovery Sheet (abandonment flow — "you left 47 min ago, resume or discard?"). Empty States set (per surface: empty logger, empty PR feed, empty branch dashboard — 21st-magic won't get these right).
  • Monorepo pipeline for tokens (Winston). pnpm workspace with packages/tokens exporting from one source three artifacts: tokens.ts (RN/Tamagui), tokens.css (Angular CSS vars), tokens.json (Style Dictionary input for future Figma sync). One build-tokens.ts script runs in CI on every PR touching packages/tokens/**. Drift becomes impossible.
  • Liquid Glass needs a real blur library + Android fallback (Winston + Sally). Reanimated handles transforms + opacity but not backdrop-filter: blur. Add @react-native-community/blur (UIVisualEffectView on iOS, RenderEffect on Android 12+). Android < 12 fallback = gradient overlay, not true blur. Restrict to nav + Active Session hero only (never on tables/lists).
  • Add react-native-skia for orb hero only (Winston). +2 MB bundle, acceptable for orb hero (gradient morphing / shape distortion / noise) but not every screen.
  • Tamagui Babel plugin with optimize: true from day one (Winston). Default install adds ~80 KB JS + runtime style resolution (150–200 ms cold-start cost on Pixel 6a). Compile-time flattening recovers this. Budget cold-start delta with plugin off vs on — fail if < 120 ms improvement (means misconfigured). Lock in README: Expo dev client required, not Expo Go (Reanimated + Gesture Handler are native modules).
  • Tamagui setup in "Phase 0.5" (John). Phase 0 = auth + schema + RBAC per PRD. Tamagui setup + one throwaway practice screen belongs in a dedicated week between Phase 0 close and Phase 1 kickoff. Don't bolt onto Phase 0; don't discover during Phase 1.
  • Realtime transport (WS vs polling) decided in Phase 0 (John). Currently flagged unresolved in CLAUDE.md. SM-3 Co-Edit gate requires this decision before Phase 1.
  • Feature flags wired Phase 0 (John). SM measurement (onboarding A/B, AI suggestion variants) needs this from day one.
  • WCAG CI via pa11y-ci (web) + wcag-contrast Node script (RN) (Winston + John). GitHub Action on PR (not pre-commit, too slow). Input = static tokens.contrast-matrix.json. Fail build if any (text, bg) pair drops below 4.5:1. Phase 0 must-have — onboarding completion SM-6 ≥ 60% depends on legibility.
  • ESLint guardrail blocking raw hex (Winston). no-restricted-syntax rule in /components/**. Plus a brand-lock allowlist file enumerating orb / wordmark / PR-watermark components that may import --vis-amber-* directly. Everything else imports --gc-accent only. Stops 21st-magic generated output from leaking off-palette hex.
  • "Adapt to Vis tokens" = 5-step gated checklist (Sally). (a) replace every hex with var(--gc-*) or Tamagui theme key, (b) replace shadow stack with 3-layer amber falloff from CLAUDE.md, (c) verify against reference_light.png + reference_dark.png, (d) WCAG contrast check, (e) light + dark screenshot diff. No merge without all five.
  • 6 gesture maps documented Phase 0, not Phase 2 (Sally). One per equipment type (cable, barbell, dumbbell, machine, bodyweight, kettlebell, bands) before build. Otherwise each Logger drifts and the grammar consistency moat collapses.
  • CDK + Tailwind preflight scoping (Winston). Tailwind's preflight reset must skip .cdk-overlay-container to avoid breaking CDK's z-index stack. One line in tailwind.config.js.
  • Voice fallback flagged for v1.1 spike (Sally). RN voice story is thin; needs native module wrapper. Budget time before v1.1 — don't discover the gap mid-build.

Each agent's full take

🎨Sally — UX Designer interaction grammar · brand fidelity

Stack is fine; inventory + "adapt to tokens" step are where this leaks.

1. Inventory gaps (not nitpicks). Presence Avatar Stack (who's editing live), Conflict Toast (LWW moment), Risk Banner (ACWR with primary action — different from a toast), Ghost Set Row (AI accept/dismiss — different interaction model from standard Set row, don't bolt on), Session Recovery Sheet (abandonment with partial-set preview), Empty States set (21st-magic won't get these right).

2. Reanimated 3 covers it — except Liquid Glass blur on Android < 12. Spec gradient-overlay fallback. Don't discover this in QA.

3. Gesture Handler adequate — but pin 6 gesture maps in Phase 0. Six logger vocabularies (FR-8). Documented before build. Otherwise each logger drifts.

4. "Adapt to Vis tokens" is hand-wavy. 5-step checklist required. Replace hex with var, replace shadow stack, verify brand-ref PNGs, WCAG check, light+dark screenshot diff. No merge without all 5.

5. Voice fallback risk. Tamagui/RN voice story thin. Native module wrapper needed. Budget spike before v1.1.

📋John — Product Manager PRD intent · SM coverage · sequencing

1. Tamagui learning curve vs Phase 0 timeline. Phase 0 = auth + schema + RBAC (zero user-facing). Tamagui setup belongs in a dedicated "Phase 0.5" week between Phase 0 close and Phase 1 kickoff. Bolting onto Phase 0 pulls launch right.

2. Phase 0 gaps that gate SMs. Shared token package verified end-to-end across all apps (SM-6 visual parity), realtime transport decision (SM-3 Co-Edit), feature flags (SM measurement A/B).

3. Inventory traceability — Liquid Glass nav/hero has no FR anchor. Composer maps to FR-PR-Moment, KPI cards map to Owner FRs, but Liquid Glass nav is aesthetic polish. Push to v1.1.

4. WCAG contrast CI = Phase 0 must-have. SM-6 ≥ 60% gated on legibility; warm-ivory + amber is exactly the combo that fails 4.5:1 if anyone hand-tweaks. CI catches drift cheaper than QA.

5. 21st-magic fit. CLAUDE.md already mandates it. Add the one-line rule: magic output adapted to var(--gc-*) before commit, never landed raw.

Net: Path B is right; sequencing is the risk. Phase 0.5 week, realtime now, Liquid Glass to v1.1.

🏗️Winston — System Architect timing · dependencies · failure modes

Six seams worth tightening before Phase 0 ships.

1. Tamagui cold-start. Default install ~80 KB JS + runtime style resolution → ~150-200 ms parse/eval on Pixel 6a. Enable @tamagui/babel-plugin with optimize: true day one. Budget delta plugin off vs on; if < 120 ms improvement, misconfigured. EAS Build + Expo dev client fully compatible (no custom native). Reanimated + Gesture Handler need dev client build, NOT Expo Go. Lock in README.

2. tokens.ts pipeline. No git submodules — sync drift is brutal. pnpm workspace monorepo with packages/tokens exporting tokens.ts + tokens.css + tokens.json from one source. build-tokens.ts in CI on every PR touching /packages/tokens/**.

3. Reanimated 3 limits. Handles transforms / opacity / shared values on UI thread — fine for orb scale/rotate, tension-stem pulse, PR Moment choreography. No backdrop-filter: blur in RN. Add @react-native-community/blur for Liquid Glass. For orb gradient morphing with shape distortion or noise, add react-native-skia (+2 MB bundle, acceptable for orb hero only).

4. CDK + Tailwind overlay. No conflict. CDK Overlay uses absolute positioning with inline styles; Tailwind utilities don't apply to CDK-injected DOM unless opted in. Scope Tailwind's preflight away from .cdk-overlay-container.

5. 21st-magic guardrail. Generated components will absolutely leak raw hex. ESLint no-restricted-syntax blocking hex literals in /components/**. Brand-lock allowlist enumerates orb / wordmark / PR-watermark.

6. WCAG CI. pa11y-ci (web) + custom Node script using wcag-contrast (RN) against static tokens.contrast-matrix.json. GitHub Action on PR. Pre-commit too slow. Fail if any (text, bg) pair < 4.5:1.
