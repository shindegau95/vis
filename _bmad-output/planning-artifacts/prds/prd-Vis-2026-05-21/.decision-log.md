### Discovery clarifications (2026-05-21)

10. **v1 user types:** **Both solo + gym-attached** ship day 1. RBAC supports six role-contexts: solo trainer, solo client, gym trainer, gym client, gym staff, gym owner. Onboarding has two paths: "I'm a trainer/client (solo)" vs "I belong to a gym".
11. **No-PT user mode:** **Self-directed log only.** No AI programming for no-PT users in v1. They get the intuitive logger + their own free-form program + Progression Index. AI exercise/macro generation is a **trainer-only tool v1** (cost containment). AI for solo users = v2 candidate.
12. **Trainer leverage on PT separation:** **Read-only past programs + alumni list.** No re-engagement messaging v1. Trainer keeps view of past client programs they wrote + alumni list. Client retains their own history. Re-engagement messaging deferred.
13. **Intuitive-input equipment scope v1:** **All gym staples** — cable, barbell, dumbbell, machine pin-stack, bodyweight, kettlebell, bands. Big UX investment but matches core differentiator. Numeric-keypad fallback always available.
14. **Entry-point order:** facilitator-suggested — Vision → Personas+Journeys (trainer↔client core) → Vision+Features (gym/admin layer) → Cross-cutting → Out-of-scope → Success metrics → Finalize.

### Vision (locked 2026-05-21)

> Vis makes progressive overload effortless for anyone who lifts — solo or with a trainer.
>
> Where competitors force gym-goers to type weights and remember last week, Vis logs through visual gestures that mimic the equipment in front of you: drag the cable pin, snap plates onto a bar, slide the dumbbell rack. Where competitors silo lifters, trainers, and gyms into three apps, Vis is one product where a trainer and client can edit the same set log live during an in-person session — and where a gym can run that experience across all its branches.
>
> Free at launch. Global from day one. India-anchored, cinematic in feel, evidence-based in method.

Three load-bearing assertions:
1. Primary user pain = remembering + inputting progression. Visual logging is THE differentiator.
2. Trainer↔client real-time in-person collab + multi-branch ops are the structural moats.
3. Free v1; pricing later. Global units + locales day 1.

### UJ-1 (Trainer + client mid-session) — captured 2026-05-21

User narrated full lat-pulldown session in detail. Pain points + 12 FRs extracted. See PRD §Personas-Journeys when drafted.

**UJ-1 specific decisions:**

15. **Warm-up sets:** separate rows, marked as warm-up by trainer, excluded from Progression Index + volume metrics.
16. **Rest timer:** in scope v1. Auto-start on set log. Configurable defaults per exercise (compound 2–3 min, isolation 60–90 s). Trainer override per client × exercise.
17. **Progression suggestion engine:** **Both modes** — trainer-typed rules (double-progression, linear, RPE-based, DUP) AND AI-suggested. Trainer picks mode per client × exercise. Most flexible. Architecture: rules engine v1, AI suggestion via Claude proxy w/ prompt caching, per-user toggle.
18. **Prescribed vs Actual:** stored as separate fields per set. Progression Index reads `actual`. UI shows both when divergent.
19. **Failure flag + RIR target:** trainer flags "to failure" intent → Vis records RIR target = 0 → actual RIR derived from actual reps vs prescribed.
20. **Superset + drop set:** composed via gesture (tap-to-pair adjacent exercises; tap-to-drop then weight picker for new load). No typing.
21. **Per-(trainer × client × exercise) progression rule:** when client switches trainer, client's rule set persists; new trainer can adopt or replace.
22. **Real-time co-edit:** Trainer App + Client App on same set log via WebSocket; last-write-wins per row.

33. **Plan-block reminders:** trainer FCM push at T-2 days before plan/phase expiry, and at expiry, until acknowledged or new block assigned.
34. **Cardio-aware logging:** v1 covers treadmill, elliptical, bike, rowing, free-form (mode + duration + avg HR + perceived effort).
35. **Trainer public profile card:** name, photo, certifications + verified badge, years experience, specialty tags, client rating, response-time stat, languages. Visible in browse + on assigned client's home.
