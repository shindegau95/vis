§1 Inspiring Products Analysis

Three explicit sources, each picked for a specific lesson. Vis ships its own visual identity — these are pattern donors, not aesthetic models.

Aesthetic + AI coach

Bevel

somewhat-inspired, calm holistic dashboards
Learn:
  • Conversational AI coach UX feels approachable, not jargon-heavy
  • Holistic dashboard pulls multiple metrics into one calm surface
  • Biological-age tracking models the "earned metric" that proves AI is working
  • Confidence display + dismissal grammar on AI suggestions
Leave behind:
  • Generalist health framing — Vis is strength-focused
  • Premium-priced AI coach model — Vis is free v1
  • Full chat surface — Vis v1 has no chat
Charts + data viz

Apple Health

graph rendering language
Learn:
  • Line-chart rendering style for Body Measurements + Strength Progress + e1RM trends
  • Segmented time-range control (Day / Week / Month / 6M / Year) on Progress Tab
  • Health categories as colour-coded chips → muscle-group recovery chips
  • Sparkline-on-card pattern for at-a-glance KPI cards
Leave behind:
  • Generic blue/red Apple semantic palette — Vis uses tangerine-amber
  • Forms-heavy empty-state posture
  • Sterile white chrome — Vis uses warm ivory bg
Training-specific UX

Motra (ex-Train Fitness)

recovery-aware programming
Learn:
  • Recovery-aware routine generation — readiness inputs shade today's prescription
  • Exercise-history-first home (the lift is the entity)
  • Compact Set row with inline RIR/RPE — no separate sheets
  • AI-Coach prompt design that's lift-specific, not generic
Leave behind:
  • Apple-Watch-only logging — wrist motion can't detect leg lifts reliably
  • iOS + Watch lock-in — Vis is RN cross-platform
Own work — locked-in

Vis prototype + orb + wordmark

visual identity ancestor
Keep:
  • Orb gradient stack recipe (radial + linear + smoked-glass top)
  • Vis wordmark glyph — orb replaces i-dot, sharp 45° v, tight s terminals
  • Liquid Glass material on nav + hero only (per §17.4 original spec)
  • Geist + Geist Mono typography pair
  • Warm ivory bg, peach-tinted shadows, no pure white/grey

§3 Anti-Patterns to Avoid

Four named anti-patterns. Each violates a stated principle from prior steps.

1MyFitnessPal-style data interrogation
Long calorie-entry forms, judgmental "you went over your goal" copy, anxiety-inducing macro pie charts. Implication for Vis: no daily calorie tracking v1 (consistent with PRD §6.2 v2 deferrals); macro plan stays trainer-authored + client read-only.
violates Emotional Principle 3 — Dignity in failure
2Gym-management dense-table ops UI (Mindbody / Glofox)
Corporate-blue chrome, dated dense tables, spreadsheet feel. Implication for Vis Admin Web: tables stay solid (per Liquid Glass "content leads" rule) but on warm cream bg with amber accents and generous spacing — not white-on-grey corporate.
violates Cross-app brand parity (quality bar)
3Hyper-bro lifting community aesthetic (Bodyspace, /r/bodybuilding-style)
Anatomy line drawings, dark machismo, neon-yellow accents, intimidating gym-bro copy. Implication: copy tone stays gender-neutral, low-key competent; no anatomy illustrations; PR cards land restrained, not aggressive.
violates Emotional Principle 4 — Presence without surveillance
4Fitbod-style gamified celebration
Confetti PR animations, XP bars, "level up!" badges, streak-loss anxiety. Implication: PR cinematic ≤ 1.5 s, dismissible; no XP; streak heatmap renders as data, not as scolding.
violates Emotional Principle 1 — Earned over celebrated

§4 Design Inspiration Strategy

Clear stance on what to adopt, adapt, and reject. Plus the new accent-customization requirement.

✓ Adopt

  • Apple Health graph language on Progress Tab
  • Bevel calm dashboard layout on Client Home + Trainer Today
  • Motra compact Set row with inline RIR/RPE
  • Apple iOS 26 Liquid Glass on nav + hero only
  • Own orb recipe + Vis wordmark — locked-in

~ Adapt

  • Bevel AI coach UX → NOT a chat surface v1; shapes ghost-overlay confidence display + override microcopy
  • Motra recovery-aware programming → recovery shades trainer's recommendation, never auto-rewrites v1
  • Notion workspace switcher → branch-scope chip in nav

✕ Avoid

  • MyFitnessPal data interrogation
  • Mindbody/Glofox dense ops UI
  • Bodyspace bro-culture aesthetic
  • Fitbod gamified celebration
  • Direct visual mimicry of Bevel/Apple Health/Motra — Vis ships a fresh new UI
★ New v1 requirement

User-customizable accent color

Default highlight is tangerine / deep amber (--vis-amber-primary / --vis-amber-deep). Each user can override from Profile → Appearance → Accent. Curated preset set v1 — not a full RGB picker, to preserve aesthetic coherence:

Tangerine (default)
Ember red
Rust gold
Sage green
Slate teal
Dusk plum

Brand-locked surfaces stay amber regardless of user choice: the orb (all 5 tension states), the Vis wordmark, the watermark on PR cards. The override applies to CTAs, focus rings, selected-state tints, ghost-overlay color, and chart accents. CSS-variable architecture supports it day 1 via theme tokens — even if v1 ships only the default and the presets land in a follow-up.
