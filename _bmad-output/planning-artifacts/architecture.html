Q5 Decision: AI History Scope Resolved 2026-05-24

Previously a BLOCKER for Driver 2. Resolved via party-mode round with Winston (Architect), John (PM), Mary (Analyst), Sally (UX). All four converged on Hybrid.

Decision: Hybrid — two layers, two scopes

Data LayerScopeRationale
Raw set logs (weight, reps, RIR) Human-identity, 90-day rolling window Client's physiological record. 90-day bound = stable cache key + efficient query.
AI suggestion history (what was recommended / accepted) Trainer-identity DPDPA/GDPR: aggregating behavioral history across relationships requires explicit consent. Safe default — resets per relationship.
Prescription notes / program structure Trainer-identity Trainer's methodology/IP. Excluded from cross-trainer AI context.

Claude Prompt Structure

// Stable cacheable prefix (human-identity layer — high cache hit rate)
cache_key = hash(client_id + exercise_id + 90day_set_log_hash)
prefix    = [client_id, exercise_id, 90-day set log: weight/reps/RIR per set]

// Dynamic suffix (trainer-identity layer — appended after cached section)
suffix    = [current trainer's prescription context, current program]

Client Consent Gate

  • Default: new trainer sees client's 90-day raw set log automatically
  • Full history (pre-90 days): explicit client consent toggle — "Share full training history with [Coach]?"
  • Ghost overlay chip: context source shown — "Based on your training history" vs "Based on sessions with [Trainer]"

v2 Upgrade Path

Trainer-facing toggle to include prior trainer programs as AI context — not in v1. Door stays open.
