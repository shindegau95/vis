How to evaluate

Compare directions against these criteria:

  • Anchor priorities (locked): does the direction serve Equipment-Aware Logger fidelity + real-time co-edit + multi-role context?
  • Persona fit: which personas does it serve best? Which does it under-serve?
  • SM coverage: does it visibly support the success metrics (SM-1 WALS, SM-3 Co-Edit, SM-5 PR share, SM-7 Trainer monitoring, SM-8 Audit query)?
  • Cross-surface coherence: can the direction extend cleanly to Trainer Today, Active Session, Progress Tab, Owner Dashboard?
  • Brand discipline: does it honor cinematic restraint + warm cream + orb-as-only-icon?

Most projects pick one primary direction as the dominant visual approach, then borrow specific elements from others where surface-specific needs differ (e.g., Active Session might lean Direction 4 even if the rest of the app is Direction 1).
